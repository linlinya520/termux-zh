# Termux-zh
该项目不只适用于 Termux，设计上兼容标准 Linux 环境（Termux 作为特殊环境处理）。

> ⚠️ **免责声明**
> 本项目由 AI辅助生成，作者本人不长期维护，也不保证长期可用或兼容性。
> 仅供娱乐和学习参考，使用风险自负。

**作用与功能：**

- 为 Termux / Linux 用户提供一个中文命令层，让常用命令可以用中文输入
- 支持文件操作、系统管理、网络操作、Python / Node / Git 包管理、文本处理、进程管理等
- 中文命令全局可用，用户态安装，不覆盖系统命令
- 提供安装 / 卸载脚本和自动生成中英对照表功能
- 可选的错误信息中文解释层（仅在中文命令下生效）

**使用建议：**

- 仅用于探索和实验，不适合生产环境
- 任何问题或损坏均由用户自行承担

## ✨ 项目目标

> 为 Termux / Linux 提供**全局可用的中文命令层（Chinese Command Layer）**
> 不修改系统、不覆盖英文命令、用户态安装、可随时卸载。

Termux-zh 的目标不是“替代 Linux”，而是**在不破坏原有生态的前提下，让中文用户更容易使用命令行**。

- ✅ 可选的错误信息中文解释层（bin-error）

## 🔧 错误信息中文化（bin-error）

Termux-zh 在部分常用命令中提供了**可选的错误信息中文解释层**：

- 仅在中文命令下生效
- 不修改、不覆盖原始英文命令
- 先输出原始英文错误，再给出简要中文解释与建议
- 只做“解释”，不自动执行任何修复操作

该机制基于 bin\-error/ 目录中的包装脚本实现，
在运行期由中文命令自动跳转，不进入 PATH，不影响系统行为。

示例（以删除命令为例）：

```text
 rm: cannot remove 'shell': Is a directory ❌ 目标是目录 ℹ 这是一个文件夹而不是普通文件，如需强制删除请使用 删除 -rf
```

该功能为实验性增强层，可独立维护、随时移除，不影响原始命令执行。

## 🚀 安装
⚠️ 如果之前安装过旧版本，请执行：
hash -r
以清除 shell 的命令路径缓存
```bash
git clone https://github.com/linlinya520/termux-zh.git
cd termux-zh bash install.sh
source ~/.bashrc
```

安装完成后，中文命令即可在任意目录全局使用。

## 🧹 卸载

```bash
bash uninstall.sh
```

卸载将：

- 删除安装的中文命令
- 移除 shell function
- 清理 .bashrc 中的相关配置

> 不会影响任何原有英文命令或脚本。
卸载后请运行 source ~/\.bashrc 使其生效。

## ⚡ 自动化文档生成

Termux-zh 提供脚本以自动生成文档，保证代码与文档一致。

- 1️⃣ 自动生成 COMMANDS.md

```bash
bash 自动生成commands.sh
```

- 扫描 bin/ 与 shell/functions.sh
- 自动列出所有中文命令
- 避免注释、颜色和重复信息污染

- 2️⃣ 自动生成中英对照表

```bash
bash 自动生成中英对照表.sh
```

- 扫描 bin/
- 抽取每个脚本最后一条核心命令
- 自动去除 exec 前缀
- 生成 mapping.txt

## 📐 设计原则

- 中文动词优先，语义明确
- 一个命令只做一件事
- 不覆盖、不劫持英文命令
- 不使用 alias，保证可卸载性
- 所有增强均为“附加层”，不是替代层
- 错误信息中文化仅作为解释层存在，不修改原始命令行为
